## Architecture and dependencies

The example is an isolated React + TypeScript + Vite application. MUI Core provides the themed controls and layout primitives; MUI X Data Grid Community provides sorting, pagination, virtualization-ready rendering and keyboard-oriented grid behavior. Emotion is MUI's styling peer. Playwright, Chromium and axe-core provide browser and supporting accessibility evidence.

The data layer is deterministic local TypeScript. `?dataset=large` loads 240 synthetic rows. `?state=error` and `?state=loading` provide reproducible state fixtures. No real student data, authentication or backend is included.

## Implemented components

- Responsive permanent/temporary sidebar and header.
- Summary cards, progress visualization, “needs a closer look” list.
- Searchable, filterable MUI X directory with sorting, pagination and detail dialog.
- Loading, empty, error and successful data states.
- Skip link, visible grid/control focus, labeled form controls, reduced-motion CSS.
